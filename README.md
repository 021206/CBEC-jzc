# CBEC-jzc
跨境电商后台管理系统
# 项目介绍
本项目为跨境电商后台管理系统，主要功能包括商品管理、订单管理、用户管理、权限管理等。项目采用前后端分离的方式，前端使用Vue.js框架，后端使用Spring Boot框架。项目采用MySQL数据库存储数据，使用Redis作为缓存，使用JWT进行身份验证。
# 技术栈
前端：Vue.js、Element UI、Axios
后端：Spring Boot、MyBatis、MySQL、Redis、JWT
# 项目结构
本项目采用前后端分离的方式，前端代码位于frontend目录下，后端代码位于backend目录下。前端代码使用Vue.js框架，后端代码使用Spring Boot框架。项目采用MySQL数据库存储数据，使用Redis作为缓存，使用JWT进行身份验证。
# 项目部署
本项目部署在阿里云服务器上，使用Nginx作为反向代理服务器，将前端代码部署在Nginx服务器上，将后端代码部署在Spring Boot服务器上。项目使用MySQL数据库存储数据，使用Redis作为缓存，使用JWT进行身份验证。
